# **SchoolScout Educational Platform**

SchoolScout is a full-stack web application designed to unify Department for Education (DfE) and Ofsted datasets. The platform enables users to find and compare local schools efficiently. It was developed as a university Final Year Project.

## **Core Features**

- Radius-based geographic filtering for precise school discovery.
- Integration of official Ofsted and DfE academic performance metrics.
- Display of comprehensive institutional contact information.
- Side-by-side comparative analysis of selected schools.
- Interactive spatial mapping for geographical data visualisation.
- Automated database schema migrations during system deployment.

## **Technology Stack**

- Frontend: React, TypeScript, Tailwind CSS, Leaflet.js
- Backend: Java, Spring Boot (Microservices)
- Database: PostgreSQL, PostGIS
- Infrastructure and DevOps: Docker, Nginx, Flyway
